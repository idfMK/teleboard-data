# Teleboard open dataset: the most active public Telegram groups, by language

The 1,000 most active **public Telegram groups** for each major language, measured, not self-reported,
from [Teleboard](https://telegram.exposed), a directory that re-checks every group and retires the ones
that go silent. Updated weekly (last update **2026-11-09**).

- **369,062** live public groups in **84** languages pass the activity rule today;
  this dataset carries the top 1,000 per language (where a language has at least 1,000 live groups)
  plus a global top 1,000 (`data/all.*`).
- Every row links to its Teleboard page: live numbers, 30 days of history and the join button are there.
- Public metadata only: title, @username, language, country, category, member and activity counts. No
  member lists, no message text. Groups marked adult, hidden, with faked members or suspicious online counts
  are left out, the same rule as the public boards.

## Columns

| Column | Meaning |
| --- | --- |
| `rank` | Position by `activity_score` within the file |
| `teleboard_url` | The group's page on Teleboard (numbers, history, join) |
| `chat_id` | Telegram chat id (stable) |
| `username` | Public @username on Telegram |
| `title` | Group title as seen on Telegram |
| `language` | Detected main language of the conversation (ISO 639-1) |
| `country` | Inferred country when the content makes it clear (ISO 3166-1 alpha-2), else empty |
| `category` | Teleboard topic (40 categories) |
| `members` | Members at the last check |
| `online_now` | Members online at the last check |
| `posters_7d` | Distinct people who wrote in the last 7 days (the core activity signal) |
| `msgs_per_day` | Messages per day over the sampled window |
| `last_msg_at` | Date of the last message seen |
| `activity_score` | Teleboard's 0-100 activity score ([method](https://telegram.exposed/methodology)) |
| `is_board` | `true` for classifieds / ad boards (listed, labelled, demoted on the site) |

## Method, in one paragraph

Teleboard reads only public groups. For each one it measures how many different people wrote in the last seven
days, messages per day and the share of members online, re-checks on a cadence tied to the group's size and
activity, and retires a group that goes quiet. Member counts alone say nothing (a bought audience is a member
count); the rows here are ordered by measured conversation. The full method, including what is refused, is at
[https://telegram.exposed/methodology](https://telegram.exposed/methodology); a monthly "State of Telegram groups" summary is at [https://telegram.exposed/data](https://telegram.exposed/data).
